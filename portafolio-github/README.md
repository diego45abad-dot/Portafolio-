# Portafolio de Diego Abad

Portafolio personal de diseño gráfico (HTML, CSS y JavaScript, sin dependencias).

## Estructura
- `index.html`: la página completa
- `img/`: foto de perfil e imágenes de los proyectos
- `pdf/`: PDF de los trabajos

## Cómo publicarla con GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `portafolio`), público.
2. Sube el contenido de esta carpeta (no la carpeta en sí): `index.html`, `img`, `pdf`.
3. Ve a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guarda.
5. En 1 o 2 minutos tu página estará en `https://TU-USUARIO.github.io/portafolio/`.
